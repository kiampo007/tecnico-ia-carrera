Modelo de Máxima Expresión

La carrera forma criterio técnico verificable. Toda evidencia debe demostrar:

  • Modelo mental experto externalizado
  • Ciclo de diagnóstico y rediseño
  • UDL como sistema (múltiples formatos válidos)
  • Transferencia
  • Juicio bajo incertidumbre
  • Criterio técnico real

Estructura

4 Fases con Gates de progresión. Se necesita ≥75 % y cumplir los mínimos para avanzar.

Fase 1 – Modelo Base

Objetivo

Construir y externalizar un modelo inicial de sistemas de IA inclusivos.

Módulos

  • Python para IA
  • Fundamentos de IA y Design Thinking
  • UDL y Accesibilidad
Gate 1 – Mínimo: Modelo externalizado + decisión de diseño justificada + aplicación explícita de accesibilidad.
Aceptable: “Elegí esta estructura porque permite que alguien con menos experiencia técnica entienda el flujo.”
No aceptable: Código sin ninguna justificación de diseño o inclusión.

Fase 2 – Diagnóstico

Objetivo

Confrontar fallos reales de modelos y aprender a diagnosticarlos y corregirlos.

Módulos

  • Machine Learning supervisado y no supervisado
  • Diagnóstico y visualización de errores
  • Ética y sesgos
Gate 2 – Mínimo: Fallo documentado + diagnóstico de la causa + corrección o rediseño fundamentado.
Aceptable: “El modelo fallaba en la clase minoritaria por desbalanceo; apliqué sobremuestreo y mejoró el recall.”
No aceptable: Solo métricas finales sin explicar ningún fallo.

Fase 3 – Extensión

Objetivo

Extender el modelo a sistemas generativos y agentes bajo restricciones reales.

Módulos

  • LLMs y Prompting
  • RAG
  • Agentes
Gate 3 – Mínimo: Arquitectura justificada bajo al menos dos restricciones reales + limitaciones reconocidas.

Fase 4 – Capstone

Objetivo

Ejercer juicio bajo incertidumbre y pensamiento de ciclo de vida.

Módulos

  • MLOps aplicado
  • UX para IA
  • Capstone
Capstone – Mínimo: Sistema desplegado + elemento de producción real + defensa de decisiones con información incompleta + análisis de límites + checklists con reflexión.
Producción real aceptable: “Logs básicos de errores + repositorio con al menos dos versiones comentadas del modelo o prompt.”
No aceptable: Solo enlace de despliegue sin registro, versión o proceso documentado.

Rúbrica (Gates y Capstone)

  • Criterio técnico y diagnóstico (40 %): Explica por qué funciona o falla y qué decisión tomó.
  • Modelo mental y justificación (30 %): El modelo mental es visible y usable.
  • Cumplimiento de mínimos (30 %): Incluye todos los elementos exigidos.

Escala: 90-100 excelente · 75-89 suficiente · <75 no aprueba.

Ponderación por fase: 80 % actividades técnicas + Gate · 20 % Método Mental.

Método Mental

Quizzes de aplicación + entregas Feynman + reflexiones. Se evalúa por calidad del modelo mental, no por completación.
